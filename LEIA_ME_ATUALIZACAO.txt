PAIVA Motion Studio V5.83 — Organização e botão Salvar ficha

Atualização de três arquivos:
body-proportions.js
paiva-attendimentos.js
sw.js

1. Extrair o ZIP.
2. Enviar esses três arquivos para https://github.com/eduardostt3dma/paiva-v5-23/upload/main
3. Confirmar em Commit changes.
4. Recarregar o programa no Chrome com Ctrl+Shift+R.

O painel de proporções aparece após as medidas antropométricas e antes dos dados da bicicleta.
O botão Salvar ficha reutiliza o arquivo local IndexedDB já existente.
Para reabrir, use a seção Atendimentos. Exporte o backup JSON para preservar
as fichas fora do navegador. Fotos, vídeos e marcações 2D não são incluídos.
Não há salvamento automático: clique em Salvar ficha antes de fechar.
