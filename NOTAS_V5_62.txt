COMO PUBLICAR NO GITHUB
----------------------
1. Extraia o ZIP no computador/celular.
2. No repositorio paiva-v5-23, entre em Add file > Upload files.
3. Envie os cinco arquivos para a RAIZ do repositorio, sem pasta adicional.
4. Se o GitHub perguntar, aceite substituir os tres arquivos existentes.
5. Clique em Commit changes. Feche e reabra o aplicativo.
6. Se a versao antiga continuar, atualize a pagina ou limpe o cache do app.
